# Changelog

## 0.2.1

- First public version.
- The server serves a page with a card for every player (portrait, equipment with game icons,
  skills, character statistics, time played and sessions) and a JSON API for other websites.
- The page is in English, German, French, Spanish, Portuguese, Russian, Polish and Italian.
- The client renders the player's character off screen when the visible equipment changes and
  sends it with the rest of the card.
